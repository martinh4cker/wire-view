# WireView 0.1.0

**Development preview · 2026-11-18**

WireView turns an Android tablet into a wired secondary display for an Apple silicon Mac. Video is encoded with VideoToolbox, forwarded over USB with ADB reverse, and decoded/rendered by MediaCodec and OpenGL on Android.

## Downloads

- `WireView-0.1.0-macOS-arm64.zip` — ad-hoc signed, not notarized.
- `WireView-0.1.0-Android.apk` — development-signed APK for sideloading; not a Play Store package.
- `SHA256SUMS.txt` — SHA-256 checksums for both artifacts.

## Included

- Extended desktop or display mirroring, with saved display placement.
- Per-tablet stream settings, USB reconnect, and a small macOS menu-bar interface.
- Simplified Chinese and English UI, following the system language.
- Tested on Apple silicon Mac and one Android 13 tablet.

## Limitations

The Mac host depends on the private `CGVirtualDisplay` API. Windows host support, touch input, audio, multi-tablet streaming, and stable 90/120 fps presentation are not available. Compatibility beyond the tested Mac and tablet has not been established.
